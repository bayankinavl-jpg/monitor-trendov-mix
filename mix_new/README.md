# Реестр регуляторных изменений (опт и производство, 2026–2028)

Собирает нормативные акты ЕАЭС/РФ, затрагивающие опт и производство, со
вступлением в силу в 2026–2028 гг., и готовит реестр изменений (xlsx/json)
для банка и его клиентов.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt   # requirements.txt — без pytest, для прод-окружения
```

## Запуск

```bash
python cli.py init-db                           # создать SQLite-реестр
python cli.py run --since 2026-07-01 --until 2026-10-06
python cli.py export --format both --out data/exports/
python cli.py verify-lead --title "..." --number "..." --date "дд.мм.гггг"
```

Смок-тест за последние 3 месяца (сохраняет отчёт в `data/exports/`):
```bash
python scripts/smoke_test_3mo.py
```

Тесты:
```bash
pytest tests/
```

## Источники

- `publication.pravo.gov.ru`, `regulation.gov.ru` — первоисточники
  (`sources/pravo_gov.py`, `sources/regulation_gov.py`). **Точная форма
  их поисковых API не подтверждена вживую** — на момент написания кода
  оба сайта были недоступны из сетевого окружения разработки (TLS-таймаут
  / DNS-ошибка). Логика разбора ответа изолирована в
  `_parse_search_response`/`_parse_item` каждого модуля — при расхождении
  с реальным форматом поправить нужно только там. При недоступности
  источника запуск честно фиксирует это в журнале, а не подменяет
  новостями.
- `sources/news_scan.py` — сканер RSS новостных СМИ (РБК, Коммерсант,
  Интерфакс, ТАСС, Ведомости, Гарант.ру, КонсультантПлюс, Агроинвестор,
  Retail.ru) как источник **сигналов**, не истины. Каждая наводка
  проверяется (`sources/news_check.py`) на первоисточниках — если не
  подтверждена, карточка сохраняется со статусом «не подтверждено» и не
  попадает в xlsx.
- `sources/stubs.py` — заготовки интерфейса под `docs.eaeunion.org`
  (ЕАЭС) и `sozd.duma.gov.ru`. Последний НЕ скрапится: его `robots.txt`
  запрещает обход для всех UA кроме Яндекса/Google, а сам сайт —
  Angular SPA. Добавление нового источника в будущем — это один новый
  модуль, реализующий `sources.base.SourceClient`.

## Ограничения, которые нужно знать

- Таблица соответствий ТН ВЭД/ОКПД2 → ОКВЭД (`mappings/okved_seed.py`) —
  курируемый стартовый набор, не официальный полный перечень. См.
  `mappings/okved_seed.md`.
- Эвристики отбрасывания кадровых/наградных/технических актов
  (`config.DISCARD_KEYWORDS`) и определения продления срока
  (`config.DEADLINE_EXTENSION_KEYWORDS`) — ключевые слова, не точный
  классификатор; уточняются по мере обработки реальных актов.
- Рассылка клиентам банка не автоматизирована — только подготовка
  xlsx/json для последующей ручной отправки.
