# Монитор трендов Микс

Программа для круга Микс (Точка): каждый день собирает новости из открытых
источников и показывает на одной странице два раздела:

- **Регуляторика** — новые законы, постановления и приказы, которые
  касаются малого бизнеса в опте, производстве, IT и услугах. У каждой
  записи — оценка достоверности и её основания.
- **Тренды** — как меняется интерес к бизнесовым и рыночным темам и к
  конкурентам: доля сюжетов за неделю, месяц или три месяца в сравнении с
  предыдущим периодом, кто о теме пишет, тип тренда по STEEPLE.

Источники — 60+ RSS-лент СМИ, правовых систем, портала pravo.gov.ru,
исследовательских центров и публичные Telegram-каналы. Сайты, которые
запрещают автоматический сбор, программа не читает.

Результат — страница `data/exports/report_artifact.html`, которая
открывается в браузере, и выгрузки в Excel и JSON.

## Быстрый старт

Нужны macOS или Linux, Python 3.11+ и интернет из российской сети.

```bash
git clone https://github.com/bayankinavl-jpg/monitor-trendov-mix.git
cd monitor-trendov-mix/mix_new
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
./run.sh          # первый сбор — за 90 дней
./monitor.sh      # открыть страницу с кнопкой запуска
```

Ежедневный автозапуск в 9:00 (macOS): `scripts/autorun.sh install`.

## Что где лежит

| Файл или папка | Что это |
|---|---|
| `mix_new/README.md` | Подробная инструкция: установка, запуск, как всё устроено |
| `mix_new/sources.yml` | Список источников — правится без кода |
| `mix_new/keywords.yml` | Слова для отбора регуляторных новостей и ниши |
| `mix_new/trends.yml` | Темы трендов и список конкурентов |
| `mix_new/scripts/` | Запуск, сборка страницы, автозапуск |
| `mix_new/pipeline/`, `mix_new/sources/` | Код сбора и обработки |
| `mix_new/tests/` | Тесты: `pytest tests/` |

База данных, выгрузки и журналы в репозиторий не попадают: у каждого они
свои и создаются при первом запуске.
